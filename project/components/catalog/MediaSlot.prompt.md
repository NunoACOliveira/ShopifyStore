A labelled placeholder standing in for photography that still has to be shot.

```jsx
<MediaSlot kind="film" label="SPLASH FILM" ratio="16 / 9"
  note="surf breaking over black rock. handheld, overexposed, no colour grade." />
```

Variants: `kind` ('photo' | 'film' | 'clip'), `ratio`, `height`. The brief text is the point — write what
the photographer needs, not "image here".
