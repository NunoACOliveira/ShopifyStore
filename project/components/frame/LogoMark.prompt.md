The abstract stone mark; sits top-left in the fixed page frame on every IKKEN screen.

```jsx
<LogoMark size={110} href="/" />
```

Variants: `small` swaps to the small-size master for placements under ~40px. Never tint it, never put it
on a filled shape, never substitute type for it — if you need a text fallback, set the word IKKEN in
Newshound 700 instead.
